# ALLOG

ALLOG 프로젝트의 공통 기획 및 개발 문서를 관리하는 저장소입니다.

프론트엔드와 백엔드 소스 코드는 각각 별도 저장소에서 관리합니다.

## Repository Links

- 백엔드: https://github.com/Minimin0/ALLOG-Backend
- 프론트엔드: https://github.com/Minimin0/ALLOG-Frontend

## Repository Structure

- `docs/`: 기획서, API 명세, 시스템 설계 및 개발 문서
- `CONTRIBUTING.md`: 공통 협업 규칙
- `README.md`: 저장소 안내

## Collaboration Rules

1. `main` 브랜치에 직접 커밋하지 않습니다.
2. 문서 작업은 별도의 브랜치에서 진행합니다.
3. 작업 완료 후 Pull Request를 생성합니다.
4. 코드 리뷰 후 병합합니다.

## Commit Convention

- `docs`: 문서 수정
- `chore`: 설정 및 기타 작업
